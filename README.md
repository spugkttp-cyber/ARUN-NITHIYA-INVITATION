# Arun & Nithiya Wedding Website

A responsive bilingual (English/Tamil) wedding invitation website.

## Files
- `index.html` — page content
- `style.css` — maroon & gold styling, responsive layout
- `script.js` — live countdown, language switch and original browser-generated background music

- Venue: ARV Dhanalakshmi Thirumana Mahal, Thiruthuraipoondi, Tamil Nadu
- Theme: Maroon & Gold
- Languages: English & Tamil

## Publish free using GitHub Pages
1. Sign in at https://github.com/
2. Create a **Public** repository named `arun-nithiya-wedding` (or any name you prefer).
3. Upload `index.html`, `style.css`, `script.js` and this README to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait a minute or two. GitHub will show your website address, usually:
   `https://YOUR-USERNAME.github.io/arun-nithiya-wedding/`

## Before publishing
- Replace or supplement the design with your own couple photos if desired.
- Add exact reception and muhurtham timings when confirmed.
- Verify the Google Maps pin for ARV Mahal. The current button opens a Google Maps search for the supplied venue address.
- Tamil font is loaded from Google Fonts, so an internet connection is needed for that font. The site otherwise works as static files.

## Music
The music button starts a soft original bell-like melody generated in the browser. It starts only after the visitor taps the button because modern browsers block autoplay audio.
